# SmartCart — Frontend

React + Vite + Tailwind CSS. Ver instrucciones de arranque completas (incluyendo el backend) en el [README de la raíz del repo](../README.md).

```bash
npm install
npm run dev
```

Requiere el backend corriendo en `http://localhost:8000` (configurable vía `VITE_API_URL` en `.env`).
